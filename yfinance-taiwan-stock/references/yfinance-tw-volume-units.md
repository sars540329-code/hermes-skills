# yfinance 台灣股成交量單位

## 單位換算

yfinance 回傳的成交量是 **股（shares）**。台股習慣用**張**，1 張 = 1000 股。

| 台股說法 | yfinance 裡的值 | 備註 |
|---|---|---|
| 1 張 | 1,000 股 | 最小一單位 |
| 5000 張 | 5,000,000 股 | 常見篩選門檻 |
| 10000 張 | 10,000,000 股 | 更大門檻 |
| 50000 張 | 50,000,000 股 | 大量股水準 |

## 怎麼拿到「昨日成交量」

```python
hist = t.history(period="5d")  # 取 5 日資料
last_vol = hist["Volume"].iloc[-1]  # 最後一根 K 棒的量（近似「昨日」）
```

注意：`history()` 回傳的是**延遲報價**，不是即時資料。若想拿即時量，要另想辦法（例如直接打 API，或用其他來源）。

## 5 日均量 vs 昨日量

- `hist["Volume"].mean()` — 5 日平均，較平滑，不會被單日異動帶跑。
- `hist["Volume"].iloc[-1]` — 最後一日的實際量，反應最近一天的活動。

在篩選時通常用均值做門檻（避免單日爆量誤判），但排序可以用昨日量（反應當下熱度）。

## 門檻設定例子

| 想要的效果 | 張門檻 | yfinance 判斷式 |
|---|---|---|
| 篩出活動股 | 1000 張 | `if avg_vol < 1_000_000: continue` |
| 中量股以上 | 5000 張 | `if avg_vol < 5_000_000: continue` |
| 大盤熱門股 | 20000 張 | `if avg_vol < 20_000_000: continue` |

## 常見坑

1. **把門檻當成張來寫，結果沒幾檔過**：例如寫 `if vol < 5000: ...`，那是 5000 股（5 張）而不是 5000 張。數字小了戳錯，股價低的股票都過，股價高的反而被濾掉。
2. **用錯欄位**：yfinance 的 `info` 裡有 `averageVolume` 這個鍵，但那是**30 日均量**，不是你要的當週或昨日量。要精準用 `history()` 拿。
3. **nasdaq/美股用同一邏輯**：美股也是股不是張，但美股 1 手通常是 1 股（除非特別標示），所以不用換算。 Taiwan 是 1000 股一张，要換。
