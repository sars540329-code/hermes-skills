# 五大陷阱 checklist

## 陷阱 01：未來值（look-ahead bias）— **AI 回測最容易踩**

- **一句話**：你回測時用了「實盤當下根本拿不到的資料」
- **例子**：訊號日 vs 執行日沒分開 → 回測「今天收盤就執行」、實盤要等下一根開盤才能執行
- **白話比喻**：像考試偷看答案 — 回測時用了實盤當下根本不可能知道的資料
- **對策**：寫 prompt 給 backtester 時固定模板：
  > 「訊號日 = T 日收盤判斷、執行日 = T+1 開盤」
- **問用戶**：「你的訊號跟執行有沒有分開？是同一根 K 棒收盤就成交、還是下一根 K 棒開盤才成交？」

## 陷阱 02：存活者偏差（survivorship bias）

- **一句話**：用「今天名單」回推「過去表現」
- **例子**：回測「過去 10 年漲最多前 50 檔台股」必賺 — 但這是後見之明，10 年前你不可能知道誰會漲最多
- **白話比喻**：用「今天班上的有錢人名單」推「過去誰一定會發財」 — 廢話、回不去當時的選擇
- **對策**：用「**當時可投資的標的**」（如當時的台灣 50 名單），不要用「今天名單」
- **問用戶**：「你的標的池是 universe 是『回測當下』就能取得的、還是現在的事後名單？」

## 陷阱 03：過擬合（overfitting）— 考試背答案

- **一句話**：你調參數調到回測完美、實盤就崩
- **例子**：MA 期數從 20 調到 18、再到 17、再到 17.5… 每次都讓回測變漂亮 → 你只是在「為這段歷史調參」
- **白話比喻**：考試前把考古題背下來、考試考一模一樣的題目你都對，換新題目就垮
- **對策**：
  - 找「高原」而不是「高峰」 — 參數 ±20% 變動後績效應該穩定
  - 高階驗證方法（WFA / 樣本外驗證）日後深入研究時可再加
  - **回測完美 = 警訊**
- **問用戶**：「你這組參數是試了多少次才選到的？參數加減 20% 績效會變多少？」

## 陷阱 04：忽略成本

- **一句話**：滑價、手續費、稅都沒加，回測就漂亮
- **例子**：高頻策略回測 +30%、加上交易成本 -5%
- **白話比喻**：算薪水時忘了扣稅跟健保、看起來很多、實領才知道差距
- **對策**：
  - 台股保守估：**手續費 0.1425% × 2（買賣各一次）+ 證交稅 0.3%（賣方）**
  - 期貨保守估：**手續費 ×1.5 倍 + 滑價 1-2 點**
  - 寧願保守估高一點、實盤才不會破功
- **問用戶**：「你的回測有沒有加手續費、稅、滑價？分別多少？」

## 陷阱 05：資料探勘（data snooping）

- **一句話**：試 100 個策略，總有 1 個漂亮
- **例子**：跑 100 組參數、挑最好那組 — 那只是運氣（同樣方法去抓樂透號碼也會「找到」漂亮的）
- **白話比喻**：丟 100 次硬幣總會出現連續正面的「神奇序列」、但它不代表你有預測能力
- **對策**：**先有假說再回測**、不要回測完才找理由解釋。試越多組參數、「漂亮但純靠運氣」的結果越多，要用樣本外驗證（拿沒看過的資料再跑一次）才能分辨真假
- **問用戶**：「你是先想到『為什麼這個會賺』再去回測、還是 try and error 試出一個漂亮的？」

## 五大陷阱掃雷流程（給 AI 用）

對使用者的回測，逐項用 yes/no 形式問清楚：

| # | 陷阱 | 問句 |
|---|------|------|
| 01 | 未來值 | 「你的 prompt / backtester 有明寫『訊號日 = T 收盤、執行日 = T+1 開盤』嗎?」 |
| 02 | 存活者偏差 | 「你的標的池是當時可投資的、還是今天的事後名單?」 |
| 03 | 過擬合 | 「這組參數試了幾次?±20% 變動績效穩定嗎?」 |
| 04 | 忽略成本 | 「手續費、稅、滑價有納入嗎?分別多少?」 |
| 05 | 資料探勘 | 「先有假說才回測、還是 try and error 出一組漂亮的?」 |

任一項可疑 → 標 ⚠️ 要求使用者說明 → 評估完才能進結論。
