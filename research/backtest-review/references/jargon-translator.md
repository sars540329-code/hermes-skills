# 講話翻譯器（給 AI 拿來解釋術語給初學者用）

## 講話 3 層結構（每個指標、每個陷阱、每個結論都這樣講）

```
第 1 層: 用大白話講這是什麼(國小生版)
   → 用日常生活比喻、不准出現英文術語、不准超過 2 句話

第 2 層: 用簡單例子算給他看(國中生版)
   → 給一個小數字例題、用加減乘除、看完就懂

第 3 層: 才講專業名詞(進階補充)
   → 加上正式名稱(Sharpe / Kurtosis / Drawdown...)讓他以後查得到資料
```

## 對照範例

❌ **太專業、學員會關掉**：
> 「Sharpe Ratio 1.32 屬於健康區間 (1.0-2.0)，代表單位風險下的超額報酬合理，未觸發 lookahead bias 警戒。」

✅ **白話版**：
> **第 1 層**：「想像一下，你要評價兩個人賺錢的能力 — 不能只看誰賺多，還要看誰**比較穩**。一個人一年賺 50 萬但常常嚇到睡不著、另一個人一年賺 30 萬但每天都很安穩，後者其實比較會賺錢。Sharpe 就是在算『每承擔一份風險、能換回多少報酬』。」
>
> **第 2 層**：「假設你每年平均賺 10%、但途中起起伏伏的程度（波動）也是 10%，Sharpe 就是 1.0；如果起伏只有 5%，Sharpe 就是 2.0 — 表示你賺得一樣多、但比較穩。你這份是 1.32，代表還算穩、不是靠賭出來的。」
>
> **第 3 層**：「這個指標的正式名稱叫 **Sharpe Ratio**（夏普比率），1.0-2.0 算健康、超過 3.0 反而要懷疑是不是計算有 bug。」

## 比喻庫（術語 → 日常翻譯）

| 術語 | 比喻 |
|------|------|
| **CAGR** | 像存錢，平均一年滾出多少% |
| **Sharpe** | 賺得穩不穩、會不會嚇到睡不著 |
| **Sortino** | 只算「跌的時候」嚇人不嚇人（下跌的恐懼） |
| **MDD（最大回撤）** | 最慘的時候從高點跌多少（像登山摔下山的高度） |
| **Drawdown duration** | 摔下去後**爬回來要多久**（被套牢幾個月） |
| **Calmar** | 賺的速度 vs 摔最慘的深度，一個 CP 值 |
| **Profit Factor** | 賺的錢是賠的錢的幾倍（≥1.5 才能養家） |
| **Lookahead bias / 未來值** | 像考試偷看答案 — 用了實盤當下根本不可能知道的資料 |
| **存活者偏差** | 用「今天班上有錢人名單」推「過去誰一定會發財」 — 廢話、回不去當時的選擇 |
| **過擬合** | 把參數調到剛好「背下歷史考古題」、新題目就垮 |
| **肥尾 / Kurtosis** | 賺賠分佈的「尾巴」特別肥 = 報酬全靠少數爆發 / 黑天鵝（不是常態） |
| **VaR / CVaR** | 「最慘的 5% 情況、你會虧多少」的數字 |
| **時間集中性** | 賺錢全擠在某一年 = 那年市場剛好對你胃口、其他年都白忙 |
| **Regime（市場環境）** | 多頭=往上跑、空頭=往下跑、震盪=橫著抖 — 你的策略只在哪一種環境會賺? |
| **空手期** | 策略沒在場上的時間% — 太多代表訊號太稀、太少代表狂進出 |
| **一字漲停** | 整天買不到 — 開盤就鎖在最高價、想買的人很多但沒人賣 |
| **一字跌停** | 整天賣不掉 — 開盤就鎖在最低價、想賣的人很多但沒人買 |
| **Slippage（滑價）** | 想用 100 塊買、實際成交 100.5 塊 — 跟想的價格有差 |
| **OHLC** | 一根 K 棒記錄當天 4 個價格：開盤 / 最高 / 最低 / 收盤 |
| **ATR** | 衡量「最近股票一天大概晃多少」 — 越大代表越亂跳 |
| **Walk-Forward / 樣本外驗證** | 用「以前的資料」調參數、用「沒看過的資料」考試 — 看會不會作弊 |

## 講話 6 條原則（給 AI 自己看）

1. **先比喻、再給數字、最後才寫術語**（順序不可顛倒）
2. **不准甩 3 個英文縮寫**（Sharpe、MDD、PF 開頭就講清楚=什麼意思，不是當作學員都懂）
3. **算給他看比解釋給他聽更好**（「你 100 萬本金、跌 30 萬就是 MDD -30%」勝過「最大回撤是衡量極端風險的指標」）
4. **用「你」「想像一下」「假設」開頭**（像在跟人對話、不是寫報告）
5. **每講完一層，問一句「這樣懂嗎?」or「要我再舉個例子嗎?」**（讓使用者有機會卡關發問）
6. **絕對不准回「這是常識」「這應該知道」**（使用者可能真的不知道、這是他第一份回測）

## 例外：Action Items 與 self-check 可稍微專業

最後給「可上線 / 要修正 / 直接淘汰」結論 + 具體下一步（改什麼參數、重跑什麼）時，可以用一點點術語（因為要使用者回去執行） — 但**仍然要附 1 句話翻譯**（例：「重跑 OOS（out-of-sample，沒看過的歷史段落）驗證」）。
