# 連結規則：[[雙向連結]] 與 #標籤

```
 [[雙向連結]]  管「東西」：講到誰
 #標籤         管「種類」：這是哪一類
```

## 什麼做成 [[雙向連結]]

| 類型 | 例子 | 命名規則 |
|---|---|---|
| 公司 | [[台積電]] [[NVIDIA]] [[東京威力科創]] | 用最常見的中文簡稱；外國公司沒有通用中文名就用英文 |
| 國家／市場 | [[美國]] [[日本]] [[新亞]] | 短名 |
| 產業／族群 | [[半導體]] [[AI伺服器]] [[金融]] | 短名，不加「產業」「類股」 |
| 概念／技術 | [[HBM]] [[CoWoS]] [[先進封裝]] | 業界通用寫法 |
| 指標／數據 | [[美債殖利率]] [[VIX]] [[ISM製造業PMI]] | 不加期限，期限寫在內文 |
| 事件／政策 | [[期中選舉]] [[分裂國會]] | 不加年份，年份寫在內文 |
| 機構／央行 | [[聯準會]] [[日本央行]] | 中文通稱 |

- **同一個東西只能有一個名字。** 開寫前先掃使用者 Obsidian 裡既有的檔名與 `[[...]]`，已經有的就沿用（例如他已經用 [[TSMC]]，就不要再開 [[台積電]]）。
- 需要兩種寫法都認得時，用 Obsidian 的顯示名稱：`[[台積電|TSMC]]`（連到台積電那頁、畫面顯示 TSMC）。
- 名稱裡不能有 `\ / : * ? " < > | # ^ [ ]`，Windows 會建不出那一頁。
- 一篇筆記裡同一個東西，第一次出現做連結就好，之後可以不用每次都加。

## 什麼做成 #標籤
- 來源：`#富邦研究`
- 報告類型：`#投資月報` `#外匯週報`
- 大主題：`#總經` `#股市` `#債市` `#匯市` `#產業` `#AI`
- 標籤寫在筆記開頭的 `tags:`，內文段落最後也可以補一個。

## 串聯怎麼長出來
- 打開 [[HBM]] 那一頁，右側「反向連結」會列出所有提到 HBM 的筆記——富邦月報、新聞、你自己的研究都會在一起。
- Obsidian 的「關係圖」（Graph View）會把這些頁面畫成一張網，越常被提到的點越大。
- 這些頁面一開始可以是空的；想寫自己的觀察時，就直接在那一頁寫。
