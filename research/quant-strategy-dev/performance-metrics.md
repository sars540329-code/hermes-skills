# 績效指標與標準報告

> 每次回測都要輸出五大核心指標＋標準化報告格式。計算請用 `scripts/calc_metrics.py`，不要手刻。

## 1. 五大核心指標

```
CAGR:          年化複合成長率
Sharpe Ratio:  風險調整後報酬（年化），上下波動都算
Sortino Ratio: 只懲罰下跌的波動
Calmar Ratio:  CAGR ÷ MDD
Max Drawdown:  最大回撤幅度與期間
```

輔助指標（**同等重要，不是選配**）：勝率、Profit Factor、平均賺／平均賠、平均持有天數、每年交易次數。

**多策略比較時全部列出，不能只看 Sharpe。** Sortino 與 Calmar 常常跟 Sharpe 排名不一樣，要綜合判斷。

### ⚠️ Sharpe 與 Sortino 並列、兩個都上燈

| 指標 | 🟢 綠燈 | 🟡 黃燈 | 🔴 紅燈 |
|---|---|---|---|
| **Sortino 下行夏普** | ≥ 1.5 | 0.8–1.5 | < 0.8 |
| **Sharpe 夏普值** | ≥ 1.0 | 0.5–1.0 | < 0.5 |
| MDD 最大回撤 | 淺於 -15% | -15% ～ -25% | 深於 -25% |
| PF 盈虧比 | ≥ 1.5 | 1.2–1.5 | < 1.2 |
| WR 勝率 | ≥ 50% | 40%–50% | < 40% |

- 兩個不是二選一：Sortino 只懲罰下跌，貼近「抱不抱得住」；Sharpe 上下都算，是跟任何人溝通都對得上的共同語言。
- 表格欄位順序：策略／Sortino／Sharpe／MDD／PF／WR／燈號加總（G/Y/R）／CAGR／相對大盤超額報酬。
- 兩個燈號不一致時要講差在哪。

### ⚠️ 勝率、PF、交易次數是必交指標

任何績效報告（包括參數掃描結果表、IS/OOS 對比、參數敏感度），**都要同時呈現**：
- **勝率（WR）**：勝率高不代表好，要搭配賺賠比看
- **Profit Factor（PF）**：總獲利 ÷ 總虧損。> 1.5 算穩健，> 2.0 算優秀
- **交易次數／每年交易次數**：太少（一年 < 20）沒有統計意義，太多（一年 > 200）成本會吃掉 alpha
- **賺賠比（Payoff Ratio）**：平均賺 ÷ |平均賠|。高勝率低賺賠比＝穩穩賺小錢；低勝率高賺賠比＝靠大波段

**禁止只輸出 Sharpe／Sortino／CAGR／MDD／Calmar 而省略勝率、PF、交易次數。** 使用者需要這些來判斷策略的「手感」—— 是每天小賺，還是偶爾大賺。

### ⚠️ 交易集中性（必做）

交易次數夠多，不代表分布均勻。**要檢查交易是不是擠在特定時段**：
- **年度分布**：哪幾年最多、最少？有沒有某年完全沒交易？
- **月／季分布**：有沒有季節性集中？
- **行情分布**：多頭／空頭／盤整各幾筆？
- 80% 的交易集中在 2 年 → 策略可能只在特定環境有效

## 2. 五大核心指標深度解讀

### CAGR —— 年化複合成長率
```
CAGR = (最終淨值 ÷ 初始淨值) ^ (1 ÷ 年數) − 1
```
**重點看相對大盤的超額報酬（alpha）**，不要只看絕對數字。同一個 12%，在大盤漲 25% 的期間跟大盤跌 10% 的期間，意義完全不同。

**陷阱**：CAGR 受起點、終點影響很大。起點選在低點、終點選在高點 → CAGR 虛高。年化 > 30% 要先檢查是不是過擬合或偷看未來。

### Sharpe Ratio —— 風險調整後報酬（年化）
```
Sharpe = (年化報酬 − 無風險利率) ÷ 年化波動
Python: returns.mean() / returns.std() * sqrt(252)
```
| 數值 | 評價 |
|---|---|
| < 0 | 虧錢 |
| 0–0.5 | 很差（報酬不值得這個波動）🔴 |
| 0.5–1.0 | 普通 🟡 |
| **1.0–2.0** | **優秀** 🟢 |
| 2.0–3.0 | 頂尖（要檢查是否過擬合） |
| > 3.0 | 極度可疑，多半是 bug 或偷看未來 |

**陷阱**：Sharpe 把「大賺」也當成波動懲罰 → 用 Sortino 補強。

### Sortino Ratio —— 只懲罰下跌的波動
```
下行標準差 = sqrt( mean( min(r, 0)² ) )      ← 分母用「全部期數」
Sortino = 平均報酬 ÷ 下行標準差 × sqrt(252)
```
⛔ **不可以寫成 `returns[returns < 0].std()`** —— 只拿負報酬那幾天算標準差，分母定義跟 Sharpe 不一致，會算出錯的數字。

| 數值 | 評價 |
|---|---|
| < 0.8 | 🔴 下跌時抱不住 |
| 0.8–1.5 | 🟡 普通 |
| **≥ 1.5** | **🟢 良好** |
| > 3.0 | 很少見，先確認計算與成本 |

**解讀訣竅**：
- **Sortino 比 Sharpe 高很多** → 上漲爆發力強、下跌溫和 → 好事
- **兩者差不多** → 漲跌分布大致對稱
- **Sortino 反而比 Sharpe 低** → 下跌特別集中、特別兇 → 先確認算法是標準算法，再去看最慘那幾段發生什麼事

### Calmar Ratio —— CAGR ÷ MDD
```
Calmar = CAGR ÷ |Max Drawdown|
```
| 數值 | 評價 |
|---|---|
| < 0.5 | 差 |
| 0.5–1.0 | 普通 |
| **1.0–3.0** | **優秀** |
| > 5.0 | 通常是回測期太短 |

**用途**：回答「我每承受 1% 的回撤，一年能賺幾％？」Calmar＝2 代表「最深跌 10%，一年賺 20%，一年內就能補回來」。

### Max Drawdown（MDD）—— 最大回撤
```python
running_max = equity.cummax()
dd = (equity - running_max) / running_max
MDD = dd.min()
```
| 數值 | 評價 | 實盤能不能撐 |
|---|---|---|
| 0 ～ -5% | 極優 | 任何人都能撐 |
| -5% ～ -15% | 優 🟢 | 有經驗者可以 |
| -15% ～ -25% | 可接受 🟡 | 要強心臟 |
| -25% ～ -40% | 危險 🔴 | 多數人會中途下車 |
| 深於 -40% | 極危險 | 實務上幾乎做不到 |

**MDD 要看「幅度＋持續時間」**：跌 20% 三個月回來可以接受；跌 20% 十八個月才回來很恐怖。

## 3. 五指標綜合判讀

```
策略健康檢查樹：

1. 相對大盤有沒有超額報酬？扣完成本還剩多少？
   ├─ 沒有 → 先分析「為什麼沒有」，參數與變數掃完了嗎？不要只跑一個版本就下結論
   └─ 有 → 繼續

2. Sharpe 與 Sortino 各是什麼燈？
   ├─ 兩個都紅 → 報酬不穩，回 Step 2／Step 4
   ├─ 燈號不一致 → 講清楚差在哪（上漲那側還是下跌那側）
   └─ 至少黃燈以上 → 繼續

3. Calmar > 1.0？
   ├─ 否 → 回撤太重，加資金管理層或縮小部位
   └─ 是 → 繼續

4. MDD 淺於 -25%（不是紅燈）？
   ├─ 否 → 考慮用回撤調節的資金管理（附件 money-management.md 的 M8）
   └─ 是 → 通過！進入穩健性驗證（WFA／蒙地卡羅）
```

**致命組合（先停下來查 bug）**：
- Sharpe > 2.0 且交易 < 30 筆 → 統計不顯著
- 年化 > 30% 且 MDD 淺於 -5% → 幾乎不可能
- Sharpe > 3.0 → 先查偷看未來與成本

## 4. 標準化績效報告格式

**⚠️ 任何績效報告都要在最前面說清楚「回測配置」。**
沒有配置說明的數字沒有意義 —— 同一個策略，每筆下 10% 跟每筆下 50 萬，出來的 CAGR 與 MDD 天差地別。

```
═══ 策略績效報告 ═══
策略：           [名稱]
期間：           YYYY-MM-DD ～ YYYY-MM-DD（資料來源：雪鴞日 K／月 K…）

─── 回測配置 ───
標的：           [個股清單／股票池／期貨商品]
起始資金：       1,000,000 元
單筆部位規則：   [見下方六選一]
停損：           [固定％／ATR×n／跌破均線／無]
停利：           [同上]
最長持有：       [X 天／無限制]
手續費：         0.1425%（×1.5 保守）；證交稅 0.3%
滑價：           單邊 X%（×1.5 保守）
再投資：         是／否
存活者偏差：     [有／無，說明]

─── 績效指標 ───
Sortino：        x.xx  🟢/🟡/🔴
Sharpe：         x.xx  🟢/🟡/🔴
Max Drawdown：   -xx.x%  🟢/🟡/🔴（YYYY-MM-DD ～ YYYY-MM-DD）
Profit Factor：  x.xx  🟢/🟡/🔴
Win Rate：       xx.x%（N 勝 / M 筆）🟢/🟡/🔴
燈號加總：       GxYxRx
CAGR：           xx.x%（同期大盤 xx.x%，超額 +x.x%）
Calmar：         x.xx
平均賺／平均賠： x.xx
平均持有天數：   x.x
每年交易次數：   xx
──────────────────────────────────
附圖：權益曲線／回撤圖／月熱力圖（完整版再加滾動 12 個月 Sharpe）
```

### 單筆部位規則：六選一（一定要寫清楚）

| 規則 | 寫法範例 | 適用 |
|---|---|---|
| **A. 固定張數／口數** | 「每次 1 口小台」「每檔固定 1 張」 | 期貨、固定張數測試 |
| **B. 固定金額** | 「每筆固定投入 100,000 元」 | 個股、初步驗證 |
| **C. 固定比例** | 「每筆投入當時帳戶的 10%」 | 有複利效果，最常見 |
| **D. 固定風險** | 「每筆風險＝帳戶 × 2%，用停損距離倒推張數」 | 進階，跟停損綁在一起 |
| **E. 波動率調整** | 「每筆部位＝帳戶 × 1% ÷ ATR」 | 海龜式、跨品種 |
| **F. Kelly／Optimal f** | 「四分之一 Kelly」 | 高階，要很謹慎 |

**多標的時還要寫**：同時最多持有幾檔、單檔資金上限、訊號同時出現時誰優先。

### 不能含糊的項目
- [ ] 單筆部位規則（A–F 擇一，不能只說「分批買」）
- [ ] 起始資金（不能只說「假設資金夠大」）
- [ ] 手續費有沒有算（金額、單邊還是雙邊）
- [ ] 滑價有沒有算
- [ ] 獲利有沒有複利
- [ ] 除權息怎麼處理（個股必填；用還原價就寫「使用還原價」）
- [ ] 有沒有用融資融券／槓桿
- [ ] 存活者偏差有沒有揭露

## 6. 計算工具

- `python scripts/calc_metrics.py --equity equity.csv` → 五大指標＋燈號 JSON
- `python scripts/calc_metrics.py --equity equity.csv --trades trades.csv` → 補上勝率／PF／平均賺賠／前 5 筆占比
- `python scripts/rolling_perf.py --equity equity.csv` → 滾動 12／6 個月 Sharpe＋PNG
- `python scripts/plot_charts.py --equity equity.csv --out charts/` → 靜態圖（互動版用 `tv-chart`）
