# 籌碼集中度篩選：外資連買 N 天

使用者常用的篩選格式：**外資連買 ≥ N 天、且最新交易日單日買超 > 門檻（張）**，輸出每檔的 1/5/10/20 日累計外資買超張數（籌碼集中度）。

## 使用者規格（預設值）
- N = 3 天、單日買超門檻 = 2000 張（使用者常指定，未指定時用這組）。
- 輸出欄位：代號、名稱、今日外資買超（張）、連買天數、近 1/5/10/20 日累計買超（張）。
- 單位換算：CSV 內是**股**，呈現時除以 1000 變張數。
- 只顯示符合條件的標的，並註明掃描日與「個股總檔數 / 符合檔數」。條件太嚴只剩 1~2 檔時，主動提議放寬（N 降為 2、門檻降為 1000 張、或改看近 5 日累計門檻）。

## 做法
1. 讀 `data_tw/inst_all_1y.csv`，`code` 用 `dtype=str` 讀。
2. 過濾一般個股：`code.str.len()==4` 且不以 `0` 開頭（排除 6 碼權證與 ETF/受益證券）。
3. `df.pivot(index="date", columns="code", values="foreign_net").sort_index().fillna(0)` 得到外資矩陣。
4. 連買天數：從最新日往回數 `>0` 的連續天數。
5. 累計張數：`d.tail(n).sum()/1000`（n=1/5/10/20）。
6. `mask = (連買>=N) & (今日>門檻*1000)`，依近 5 日排序輸出。

## 踩坑
- **pandas 3.x：不要 `reversed(Series)` 或對 Series 用位置索引**，會 KeyError（label 查找撞到整數欄名）。連買天數要先 `col.tolist()` 再對 list 反轉。
- `pivot` 前一定 `dtype=str` 讀 code，否則代號被轉成整數、前導 0 消失。
- 對齊名稱：用最新日 `df[(df.date==最新)&(df.code==c)]["name"]`，直接 map 會因為 NaN/轉板代號失敗。
- 單一條件（N=3 + 2000 張）在平靜盤面常只剩個位數檔，是篩選太嚴不是資料有問題；先確認再放寬，不要急著改門檻。
- 寫 Windows 路徑的 inline python（heredoc/`-c`）：`\U`、`\t` 會被當跳脫字元寫壞路徑，用 raw 字串或 write_file 寫腳本。
- **`panel.csv` 只有 250 檔（0050 成分股），不是全市場**。要用它疊成交量門檻（如「當日量 ≥ 5000 張」）只能 inner join 交集，會把候選池從兩千多檔砍到 250 檔；join 前先印出 merged 後剩幾檔，並在輸出註明「有成交量資料的檔數」，別把交集結果當全市場篩選結果。
- **rolling 窗口要在 merge 之前算**：先對全歷史 `groupby(code).rolling(w).sum()`，再只取最新日與成交量資料 inner join。先 merge 再算 rolling，窗口被截斷、結果會靜靜地變空集合。
- **`inst_all_1y.csv` 最新日可能缺某一市場**（例：最新兩日 TWSE 0 筆、只有 TPEx）。分市場篩選前先數每個日期 × 市場的列數，TWSE 名單若為空先確認是資料未更新而非篩選無效；改用最新有完整資料的日期並在輸出註明日期。
